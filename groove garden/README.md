# groove garden

*Od samplu k live setu.* Interaktivní průvodce (CZ / EN) pro Roland SP-404MKII: jak si práci připravit, dotáhnout skladby do struktury a hrát je live.

- **Přístup** – 5 způsobů práce (Banka = skladba, Patterny + Chain, Stem jam, DJ set, DOOM OS), dotazník a srovnání výhod/nevýhod
- **Workflow** – 7 fází s odškrtávacími kroky a konkrétními kombinacemi tlačítek
- **Konvertor** – převod zvuků i celých složek na WAV 48 kHz/16 bit, chytré mono, názvy bez diakritiky, ZIP se zachovanou strukturou složek
- **Plánovač** – rozložení padů po bankách, struktura skladby, setlist, tahák na stage
- **Live**, **Zkratky** (+ postupy krok za krokem z manuálu), **DOOM OS**, **Trénink** (4 úrovně se zkouškami + timer)
- Vyhledávání v celém průvodci

Jeden soubor `index.html`, bez dalších závislostí (jen Google Fonts). Funguje i na telefonu. Data se ukládají jen v prohlížeči (`localStorage` / `IndexedDB`), zvuky se nikam neodesílají.

## Spuštění na GitHub Pages
1. Nahraj `index.html` (a tento README) do repozitáře.
2. Settings → Pages → Deploy from branch → `main` / root.
3. Stránka poběží na `https://<uživatel>.github.io/<repo>/`.

Zdroje: Roland SP-404MKII Reference Manual v5.50, oficiální seznam zkratek, Roland support (formáty importu), DOOM OS manuál (Klangfeld Labs).
Neoficiální projekt, není spojen s firmou Roland.
